# CPR 節奏訓練系統：黃金四分鐘 (v3 三模式整合版)

## 三大顯示模式（頂部按鈕或按 `V` 鍵隨時循環切換）
1. **⚙️ 模式一：FPGA 工程展示** — 物理雙 LDR 機構、4 位數紅光七段顯示器、12 顆板載 LED、血氧 SpO₂、即時 ECG 與 UART 115200 監聽終端機。
2. **🏥 模式二：遊戲畫面（可改背景與角色）** — 明亮醫院病房遊戲介面，支援點擊頂部 **「🎨 換背景/角色」** 切換內建場景（日間病房／救護車內／科技急診室）與陪伴角色（溫柔護理師／啦啦隊 Cheer1／熱血急救員／資深醫師），亦支援本機上傳自訂圖片與透明 GIF。
3. **📱 模式三：經典 v2** — 完整保留原本 `v2.html` 三欄式精簡氣囊、雙 LDR、垂直霹靂燈與生理監視器。
